# Fatima Zohra — Developer Portfolio

BSIT undergraduate portfolio built to be recruiter-ready: fast, accessible, responsive, and dark/light theme aware.

🔗 **Live site:** https://fzohraxxkz8402358-cpu.github.io/My_portfolio-/

## About

Personal portfolio for Fatima Zohra, a BSIT student at QUEST Nawabshah, showcasing real projects built through university coursework and programming internships (CodeAlpha, DecodeLabs).

## Features

- Sticky navigation with active-section highlighting
- Dark/light theme toggle, persisted in `localStorage`, respects system preference
- Accessible mobile menu with keyboard support
- Project filtering by language (All / Python / C / C++)
- Semantic HTML, visible focus states, `prefers-reduced-motion` support
- No build step — plain HTML, CSS and JavaScript in one file

## Project structure

```
My_portfolio-/
└── index.html   # entire site (markup, styles, script)
```

## Sections

- Hero — name, role, one-line statement, primary actions
- About — who I am, what I'm learning, long-term goal
- Skills — languages, database, concepts, tools
- Projects — 12 projects with filtering and links to source
- Education & Certifications — degree in progress + internship certificates
- Experience — internships (CodeAlpha, DecodeLabs)
- Contact — email, GitHub, LinkedIn

## Run locally

Clone the repo and open `index.html` directly in a browser:

```
git clone https://github.com/fzohraxxkz8402358-cpu/My_portfolio-.git
cd My_portfolio-
```

No dependencies or build tools required.

## Deployment

Hosted with GitHub Pages, serving `index.html` from the `main` branch.
